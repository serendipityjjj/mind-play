# 「마음플레이_감정일기」 풀스택 웹 애플리케이션
> **대구광역시교육청 마음학기제 중학교 워크북 기반 마음성장 & 15차시 성장 소설 문집 제작 서비스**

---

## 🌸 프로젝트 개요
학생들이 매주 목요일 15차시 교육과정에 맞춰 '마음이' 인터뷰 챗봇과 대화하고, 귀여운 8대 감정 구름 캐릭터와 사진을 기록하며, 최종적으로 축적된 15회차의 일기 데이터를 한 편의 서정적 단편 성장 소설로 각색해 문집(책)으로 엮어내는 풀스택 웹 서비스입니다.

## 🚀 1~5차시 심층 인터랙티브 모듈
- **1차시 모듈 (`Lesson1Module.tsx`)**: 오늘의 마음 편지 💌 열기 + TTS 낭독, 내 마음에 살고 있는 입주민 단어 태그 픽커, `#해시태그로 말해요` 티켓, 미래 나에게 보내는 편지 디지털 타임캡슐 자물쇠 봉인(15차시 개봉 연동), 별점 평가 & 감정일기.
- **2차시 모듈 (`Lesson2Module.tsx`)**: 강점 보석함 3개 픽커, '나다움 가면' 색상/강점 스티커/선언 문장 커스텀 빌더 캔버스, 별점 평가 & 감정일기.
- **3차시 모듈 (`Lesson3Module.tsx`)**: 자기표현 3가지 유형 밸런스 체크, '나다움 가면 소개서' 인스타그램 스타일 프로필 카드 빌더 & 발급, 별점 평가 & 감정일기.
- **4차시 모듈 (`Lesson4Module.tsx`)**: 스카이블루 테마, 감정 단어 사전 4개 계열 칩 픽커, 감정 인식의 중요성 모달, 내 마음속 감정 몬스터/캐릭터 커스텀 빌더, 감정신호등 미션 & 감정일기.
- **5차시 모듈 (`Lesson5Module.tsx`)**: 딥퍼플 테마, 마음버튼 고장 경보등 픽커, 0~100°C 감정 온도계 슬라이더 + 4-7-8 심호흡 가이드 애니메이션 모달, 나만의 감정 조절 마법 주문 카드 빌더, 별점 평가 & 감정일기.
- **6~15차시 공통 모듈 (`GenericLessonModule.tsx`)**: 15차시 전 커리큘럼 완벽 연동 및 15차시 타임캡슐 개봉식 지원.

---

## 📖 Upstage Solar 15차시 성장 소설 생성 & 플립북 뷰어
- **Novelizer (`NovelizerModal.tsx`)**: 15차시 누적 감정일기 데이터 기반, 장르(성장소설, 에세이, 판타지, 학원물) 및 어조 선택 가능. Upstage Solar API (`solar-1-mini-chat`)로 신상정보를 익명화한 서정적 단편 소설 집필.
- **Flipbook Viewer (`FlipbookViewer.tsx`)**: `#FAF6F0` 도서 종이 질감, 표지/프롤로그/목차/15개 챕터/에필로그 페이지 넘김 모션, 인쇄 및 PDF 내보내기 지원.

## 🛠️ 실행 및 배포 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 환경 변수 설정 (`.env.local`)
```env
GEMINI_API_KEY=your_gemini_api_key
UPSTAGE_API_KEY=your_upstage_api_key
GOOGLE_SHEETS_WEBHOOK_URL=your_google_sheets_webhook_url
```

### 3. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속.
